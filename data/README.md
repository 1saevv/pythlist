# Pythenians data

`pythenians.json` is generated by `scripts/build-pythenians-dataset.mjs`.
Run `npm run pythenians:refresh-metadata` after Pythenians art or level metadata
changes to update local images without recalculating ownership history.

The public dataset is safe for GitHub Pages: it contains the Pythenian number, mint,
official image URL, level, and `heldSince`. It intentionally does not contain the
current owner wallet address.
