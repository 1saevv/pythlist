# Pythenians dataset pipeline

PythList is hosted on GitHub Pages, so the frontend must not call Solana RPC or
hold API keys. The site should read the generated public file:

```text
data/pythenians.json
```

That file is generated by:

```bash
npm run pythenians:build
```

## Required GitHub Secret

Create one repository secret:

```text
SOLANA_RPC_URL
```

Use a reliable Solana mainnet RPC URL. A free-tier QuickNode or Alchemy Solana
RPC endpoint is enough to start. Do not use a Helius paid transfer API key here;
the script uses standard Solana RPC methods.

GitHub path:

```text
Repository Settings -> Secrets and variables -> Actions -> New repository secret
```

## What is public

`data/pythenians.json` contains:

- Pythenian number
- mint
- official image URL
- `heldSince`
- build-time `daysHeldAtBuild`
- `updatedAt`

It does not contain the current owner wallet address.

## What is private/cache-only

The script writes `.cache/pythenians-state.json` with owner and token-account
state so later builds can avoid recalculating unchanged NFTs. `.cache/` is
ignored by Git and restored only through GitHub Actions cache.

## Data sources

- Official image/metadata: `https://ipfs.pythenians.xyz/metadata/{number}.json`
- Official on-chain collection mint: `pyTh2UtBKfuDW6KCdT3swospYeoLmmKaGujWA91Moru`
- Metaplex update authority: `PyTHY3DyjVQe9EQVU7jYriVKd7dJ6xiyyyPvVWxpiMN`
- Ownership/transfer history: standard Solana RPC
